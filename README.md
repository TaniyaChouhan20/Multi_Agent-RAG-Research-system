# 🤖 Multi-Agent RAG Research System

## 📌 Description

This project is a Multi-Agent Retrieval-Augmented Generation (RAG) system designed to perform intelligent research by combining multiple agents, document retrieval, and large language models. It can process documents, retrieve relevant information, and generate accurate responses.

## 🚀 Features

* Multi-agent architecture for task handling
* Retrieval-Augmented Generation (RAG) pipeline
* Document-based question answering
* Modular design (agents, tools, chatbot)
* Scalable and extensible system

## 🛠 Tech Stack

* Python
* LangChain
* Groq API / Open-source LLMs
* FAISS / Vector Database (if used)

## 📂 Project Structure

```
MULTI_AGENT_RESEARCH_SYSTEM/
├── agents/
├── chatbot/
├── rag/
├── tools/
├── app.py
├── main.py
```

## ⚙️ Setup Instructions

1. Clone the repository:

```
git clone https://github.com/your-username/Multi_Agent-RAG-Research-system.git
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Create a `.env` file and add your API key:

```
GROQ_API_KEY=your_key_here
```

4. Run the project:

```
python main.py
```
